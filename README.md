В папке `release` находятся готовые к запуску программы:

- `encoder.bat` и `encoder.jar` — кодер;
- `decoder.bat` и `decoder.jar` — декодер;

Программы рассчитаны на запуск в **Windows 10**. Для работы требуется установленная **Java 16 или выше**.

## Как запускать на Windows

Если используется PowerShell, перед именем `.bat`-скрипта нужно писать `./`.

Например: `./encoder.bat "C:\Projects\mit\dataset\bib" "C:\Projects\mit\dataset\encoded"`

Далее примеры команд приведены именно для **PowerShell**.

## Как запустить кодер

Кодер запускается командой: `./encoder.bat "<input_file>" "<output_path>"`, где:
- Первый аргумент - путь к исходному файлу, который нужно сжать
- Второй аргумент - путь к тому месту, где должен появиться архив

Если во втором аргументе указана **папка**, то архив будет создан внутри неё с именем исходного файла и расширением .enc.

Например: `./encoder.bat "C:\Projects\mit\dataset\bib" "C:\Projects\mit\dataset\encoded"`, где:
- **bib** - исходный файл
- **encoded** - существующая папка, где будем хранить сжатый файл

В этом случае будет создан сжатый файл: `C:\Projects\mit\dataset\encoded\bib.enc`.

Если во втором аргументе указать не только папку, но и **собственное имя архива**, то архив с данным именем будет создан по этому пути. 
Расширение .enc будет добавлено автоматически.

Например: `./encoder.bat "C:\Projects\mit\dataset\bib" "C:\Projects\mit\dataset\encoded\bib_archive"`, где:
- **bib** - исходный файл
- **bib_archive** - имя, которое должно быть присвоено создаваемому сжатому файлу

В этом случае будет создан сжатый файл: `C:\Projects\mit\dataset\encoded\bib_archive.enc`.

Можно передавать не полные пути, а **только имена файлов**. 
В этом случае исходный файл должен лежать в той же папке, где находятся encoder.bat и encoder.jar, то есть в папке release.

Например: `./encoder.bat bib bib_archive`, где:
- **bib** - исходный файл
- **bib_archive** - имя, которое должно быть присвоено создаваемому сжатому файлу

В этом случае будет создан сжатый файл `bib_archive.enc`.

## Как запустить декодер

Декодер запускается командой: `./decoder.bat "<input_archive>" "<output_path>"`, где:
- Первый аргумент - путь к архиву, который нужно восстановить
- Второй аргумент - путь к тому месту, где должен появиться восстановленный файл

Архив можно указывать как с расширением .enc, так и без него.
Например, обе команды ниже корректны:
```powershell
./decoder.bat "C:\Projects\mit\dataset\encoded\bib.enc" "C:\Projects\mit\dataset\decoded"
./decoder.bat "C:\Projects\mit\dataset\encoded\bib" "C:\Projects\mit\dataset\decoded"
```

Здесь в первой команде:
- **bib.enc** - исходный сжатый файл, который нужно восстановить
- **decoded** - существующая папка, где будет храниться восстановленный файл

Здесь во второй команде:
- **bib** - исходный сжатый файл, который нужно восстановить
- **decoded** - существующая папка, где будет храниться восстановленный файл

Если во втором аргументе указана **папка**, то восстановленный файл будет создан внутри неё с именем архива без расширения .enc.

Например: `./decoder.bat "C:\Projects\mit\dataset\encoded\bib.enc" "C:\Projects\mit\dataset\decoded"`, где:
- **bib.enc** - исходный сжатый файл, который нужно восстановить
- **decoded** - существующая папка, где будет храниться восстановленный файл

В этом случае будет создан восстановленный файл: `C:\Projects\mit\dataset\decoded\bib`.

Если во втором аргументе указать не только папку, но и **новое имя восстановленного файла**, то результат будет записан именно по этому пути, где восстановленный файл будет иметь указанное имя.

Например: `./decoder.bat "C:\Projects\mit\dataset\encoded\bib" "C:\Projects\mit\dataset\decoded\bib_restored"`, где:
- **bib** - исходный сжатый файл, который нужно восстановить
- **bib_restored** - имя, которое должно быть присвоено создаваемому восстановленному файлу

В этом случае будет создан восстановленный файл: `C:\Projects\mit\dataset\decoded\bib_restored`.

Как и в случае с кодером, можно передавать **только имена файлов без полных путей**. Тогда архив должен лежать вместе со скриптами и jar-файлами в папке release.

Например: `./decoder.bat bib.enc bib_restored`.

В этом случае будет создан восстановленный файл: `bib_restored`.

## Как запустить подсчет статистики

Для автоматического прогона по набору файлов используется команда: `./stats.bat "<input_directory>"`.

Аргументом передаётся путь к существующей папке, в которой лежат файлы для тестирования. 
Программа последовательно сжимает и восстанавливает все обычные файлы из этой папки, проверяет совпадение исходных и восстановленных данных бит в бит, а затем вычисляет статистические характеристики и сохраняет их в CSV-файл.

Например: `./stats.bat "C:\Projects\mit\dataset"`, где:
- **dataset** - существующая папка, где лежат файлы для тестирования

После выполнения в указанной папке `dataset` будут созданы:
- **encoded** - папка, которая будет содержать сжатые файлы (полученные из файлов для тестирования)
- **decoded** - папка, которая будет содержать восстановленные файлы на основе файлов из папки encoded
- **result.csv** - csv-файл, содержащий посчитанную статистику

Можно передавать не полный путь, а **только имя папки**. 
В этом случае она должна находиться рядом со скриптами и jar-файлами в папке release.

Например: `./stats.bat dataset`.

## Пример запуска кодера и декодера

Если исполняемые файлы (`encoder.bat`, `encoder.jar`, `decoder.bat`, `decoder.jar`) находятся, например, в `C:\Projects\mit\release`, то:
```powershell
user> cd "C:\Projects\mit\release" # переход к исполняемым файлам

user> ./encoder.bat bib bib_compressed # сжатие файла bib (при условии, что он лежит в C:\Projects\mit\release) и получение сжатого файла bib_compressed.enc
user> ./decoder.bat bib_compressed bib_restored # восстановление сжатого файла bib_compressed.enc и получение восстановленного файла bib_restored
```
